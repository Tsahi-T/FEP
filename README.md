# מנהל אתר בנייה

אתר מותאם לפלאפון לניהול פרויקטי בנייה בישראל: שלבי בנייה, תקציב והוצאות, רישוי ותיאום רגולטורי, וקבלני משנה/ספקים. תומך בכמה פרויקטים במקביל.

כל הנתונים נשמרים מקומית בדפדפן (localStorage) — ללא שרת וללא התחברות. בעמוד "גיבוי ושחזור" ניתן להעתיק גיבוי יומי של הנתונים וכן לייבא אותם בחזרה.

## הרצה

פתחו את `index.html` בדפדפן, או הגישו דרך GitHub Pages.
